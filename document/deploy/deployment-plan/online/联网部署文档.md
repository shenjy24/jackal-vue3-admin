# jackal-vue3-admin 联网部署文档

## 部署方式

online 部署采用容器化运行：

```text
git fetch/pull
  -> docker build 多阶段构建
      -> node:24.17.0-slim 编译 dist
      -> nginx:1.30.2-alpine 托管 dist
  -> docker compose up -d 启动 jackal-vue3-admin-prod
```

前端容器内部仍然运行 Nginx，但只负责静态资源和 Vue Router history fallback。外部 Nginx 作为统一入口，负责域名、HTTPS 以及 `/admin/api/` 到后端 `service-admin` 的转发。部署流程不再维护 `releases/current` 静态目录软链接。

## 目录说明

```text
document/deploy/deployment-plan/online/
├── deploy.env          # online 部署变量
├── deploy.sh           # 拉取代码、构建镜像、启动容器
├── rollback.sh         # 从本地历史镜像回滚
├── Dockerfile          # Node 构建 + Nginx 运行镜像
├── docker-compose.yml  # 前端容器运行配置
└── nginx.conf          # 容器内静态资源 Nginx 配置
```

## 前置条件

部署机需要安装：

```bash
sudo apt update
sudo apt install -y docker.io git
sudo systemctl enable --now docker
```

Docker Compose 需要使用 v2：

```bash
docker compose version
```

## 配置 deploy.env

按实际环境修改：

```bash
ENV=prod
BRANCH_NAME=main
APP_PORT=18080
NODE_IMAGE=node:24.17.0-slim
NGINX_IMAGE=nginx:1.30.2-alpine
IMAGE_KEEP_COUNT=5
```

`APP_PORT` 是宿主机暴露端口，容器内固定监听 80。

## Nginx 配置

容器内 `nginx.conf` 只负责静态资源和 history fallback：

```nginx
location / {
  try_files $uri $uri/ /index.html;
}
```

外部 Nginx 负责转发 API 和前端页面，可参考 `document/deploy/nginx.conf`：

```nginx
location /admin/api/ {
  proxy_pass http://127.0.0.1:18882/;
}

location / {
  proxy_pass http://127.0.0.1:18080;
}
```

这会把前端请求 `/admin/api/admin/auth/loginByAccount` 转发为后端 `/admin/auth/loginByAccount`。如果 `service-admin` 或前端容器端口不同，需要同步修改外部 Nginx 配置。

## 部署

在仓库中执行：

```bash
cd /home/tech/workspace/jackal-vue3-admin
bash document/deploy/deployment-plan/online/deploy.sh
```

脚本会：

1. 检查 Docker、Docker Compose v2 和 Git。
2. 拉取并快进到 `GIT_REMOTE/BRANCH_NAME`。
3. 准备临时 Docker build context，使 Dockerfile 可使用 `COPY ./nginx.conf`。
4. 使用 Docker Compose 构建镜像 `jackal-vue3-admin:prod-时间-提交号` 并启动 `jackal-vue3-admin-prod`。
5. 保留最近 `IMAGE_KEEP_COUNT` 个历史镜像并清理 dangling image。

部署完成后访问：

```text
http://服务器IP:APP_PORT/
```

## 回滚

查看并选择本地历史镜像：

```bash
bash document/deploy/deployment-plan/online/rollback.sh
```

也可以直接指定序号或完整镜像名：

```bash
bash document/deploy/deployment-plan/online/rollback.sh 2
bash document/deploy/deployment-plan/online/rollback.sh jackal-vue3-admin:prod-20260624153000-abcdef1
```

回滚会复用同一个 `docker-compose.yml`，只替换 `APP_IMAGE` 并重启前端容器。

## 常用命令

查看容器：

```bash
docker ps --filter name=jackal-vue3-admin-prod
```

查看日志：

```bash
docker logs -f jackal-vue3-admin-prod
```

查看历史镜像：

```bash
docker image ls jackal-vue3-admin
```

停止服务：

```bash
cd document/deploy/deployment-plan/online
APP_IMAGE=jackal-vue3-admin:prod-placeholder docker compose -p jackal-vue3-admin-prod -f docker-compose.yml down
```

## 注意事项

- online 容器内部包含 Nginx，但不处理 `/admin/api/`。
- 宿主机外部 Nginx 需要配置 `/admin/api/` 转发到后端 admin 服务。
- `VITE_API_BASE_URL=/admin/api` 的生产配置保持不变，由外部 Nginx 代理到后端 admin 服务。
- 首次联网构建会拉取 `NODE_IMAGE` 和 `NGINX_IMAGE`，需要部署机能访问对应镜像仓库。
