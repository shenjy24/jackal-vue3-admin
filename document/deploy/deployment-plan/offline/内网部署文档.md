# jackal-vue3-admin 内网部署文档

本文档说明生产环境无法访问公网时，如何使用本地构建好的 `dist` 静态产物，在内网服务器上构建 Nginx 运行镜像并通过 Docker Compose 启动前端容器。服务器不需要 Node.js 或 npm，只需要 Docker、Docker Compose v2、上传的 `dist` 包和已加载的 Nginx 基础镜像。

## 目录结构

```text
deploy/
├── Dockerfile
├── docker-compose.yml
├── deploy.env
├── deploy.sh
├── rollback.sh
├── nginx.conf
└── jackal-vue3-admin-dist.tar.gz       # 本地构建后上传，或直接上传 dist/
```

## 本地构建

在可联网或已具备依赖的构建机执行：

```bash
npm ci
npm run build
```

构建产物位于 `dist/`。可以直接上传 `dist/`，也可以打包后上传：

```bash
tar -czf jackal-vue3-admin-dist.tar.gz dist
# 或 zip -r jackal-vue3-admin-dist.zip dist
```

将 `document/deploy/deployment-plan/offline/` 目录和 `dist` 包一起上传到服务器部署目录。

## 前置条件

服务器需要安装 Docker 和 Docker Compose Plugin，并提前加载 Nginx 基础镜像：

```bash
docker load -i nginx-1.30.2-alpine.tar
docker image inspect nginx:1.30.2-alpine
```

如果基础镜像 tag 不同，修改 `deploy.env` 中的 `NGINX_IMAGE`。

## 配置

编辑 `deploy.env`：

```bash
ENV=prod
APP_PORT=18080
NGINX_IMAGE=nginx:1.30.2-alpine
DIST_DIR=.
IMAGE_KEEP_COUNT=3
```

前端生产构建使用 `.env.production` 中的 `VITE_API_BASE_URL=/admin/api`。和 online 部署一样，前端容器只托管静态资源与 history fallback，不处理 `/admin/api/`；外部 Nginx 或网关负责把 `/admin/api/` 转发到后端 `service-admin`。

## 发布

在服务器部署目录执行：

```bash
bash deploy.sh
```

脚本会自动查找同目录下的 `dist/`、`dist.tar.gz`、`dist.zip` 或 `jackal-vue3-admin-dist*.tar.gz/.zip`。也可以显式指定：

```bash
bash deploy.sh jackal-vue3-admin-dist.tar.gz
bash deploy.sh dist
```

执行流程：

1. 校验 Docker、Compose、Dockerfile、Compose 文件和 Nginx 基础镜像。
2. 解包或复制上传的 `dist` 到临时构建上下文。
3. 构建应用镜像，例如 `jackal-vue3-admin:prod-20260624153000`。
4. 使用 `docker compose up -d --no-build` 启动 `jackal-vue3-admin-prod`。
5. 校验容器运行状态，保留最近 `IMAGE_KEEP_COUNT` 个历史镜像。

## 外部 Nginx

外部 Nginx 可参考 `document/deploy/nginx.conf`：

```nginx
location /admin/api/ {
  proxy_pass http://127.0.0.1:18882/;
}

location / {
  proxy_pass http://127.0.0.1:18080;
}
```

这样浏览器请求 `/admin/api/admin/auth/loginByAccount` 会由外部 Nginx 转发为后端 `/admin/auth/loginByAccount`。

## 发布后检查

```bash
docker ps --filter name=jackal-vue3-admin-prod
docker logs -f jackal-vue3-admin-prod
curl -I http://127.0.0.1:18080/
```

业务访问应走外部 Nginx 的域名或 IP。直接访问 `APP_PORT` 只能验证前端静态资源是否可用，不能验证 `/admin/api/` 代理。

## 回滚

查看并选择本机历史镜像：

```bash
bash rollback.sh
```

也可以指定序号或镜像名：

```bash
bash rollback.sh 2
bash rollback.sh jackal-vue3-admin:prod-20260624153000
```

回滚只切换前端容器镜像，不回滚后端服务、数据库结构或数据。

## 常见问题

### 页面可以打开，但登录接口异常

确认业务访问走的是外部 Nginx，并且外部 Nginx 已配置 `/admin/api/` 反向代理。

### 页面刷新 404

容器内 Nginx 已配置 `try_files $uri $uri/ /index.html`。如果仍然 404，确认请求确实到达前端容器，而不是外部网关的其他站点。

### 部署脚本找不到 dist 包

将 `dist/` 或 `*.tar.gz/*.zip` 上传到 `DIST_DIR`，或执行 `bash deploy.sh <包路径>` 显式指定。
